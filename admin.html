Recevoir les commandes par email (EmailJS)

Sur emailjs.com : créez un service email, puis un modèle qui s'envoie à votre adresse. Dans le modèle, utilisez ces variables : {{reference}} {{article}} {{prix}} {{nom}} {{telephone}} {{adresse}} {{paiement}} {{email_client}}.

Paiement 1 : FedaPay
Paiement 2 : lien de paiement (ex. FeexPay)
Paiement 3 : lien de paiement (ex. crypto)

Dans un lien, vous pouvez utiliser {montant} {article} {reference} {nom} {telephone}, ils seront remplacés automatiquement. Votre site est visible par tout le monde : ne mettez ici que des clés publiques, jamais une clé secrète (sk_...) ni un token privé.
